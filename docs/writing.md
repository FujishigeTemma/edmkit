# 良い文章の必要条件

## 文書の単位

- 文章の目的が明確である
- 結論を先に書くのは節の単位。節の冒頭で、その節が何を確立するかを書く。導出の内部では適用せず、原因を先、帰結を後に書く
- 読者のメンタルモデルを構築・更新していく。各文は読者のメンタルモデルに作用を持ち、持たないなら書かない
- 同じ目的、同じ主張を二度書かない
- 一つの概念に一つの名前、一つの名前に一つの概念。極力、新しい記号や用語を導入しない
- 文章全体の構造を常に意識し、各段落の立ち位置を明確にする
- 各文章単位で粒度が一貫している
- 目的は、後で使う全ての場合を含む一般性で述べる。特定の場合に限定した目的を書かない

## 文の単位

すべての文は次の二つの型のどちらかで書く。どちらでもない文は書かない。

1. 目的型: 「XXXであって欲しいから、YYYであって欲しい」「XXXであって欲しいから、YYYと仮定する」
2. 帰結型: 「XXXだから、YYYと言える」

- 目的型は、より遠い目的から、より近い手段へ向かう。「手段 so that 目的」の向きで書かない
- 目的から要求へ移るとき、その要求が目的を満たす理由を、間に帰結型の一文として書く。読者に「なぜそれが欲しいのか」と問わせたまま先へ進まない
- 一文に一つの推論。根拠と結論をセミコロンで繋がない
- 先送りしない。「後で示す」「適切な選び方をすれば」と書かない。その場で示せない主張は、置く位置が間違っている
- 文が使う語と記号は、すべてその文より前で定義されていること。読者がまだ持っていない概念で目的を述べない
- 起きない場合を防御する文を書かない
- 無意識の仮定を置かない。「YYYならXXXできる」の YYY と XXX の間に飛躍があれば、それを埋める帰結型の文を書く

## 語彙

- 数学的対象に対する動詞は数学的操作に限る。「教えてくれる」「材料」「固定される」「自由に残る」「代わりを務める」のような比喩を使わない
- 比喩的な表現や解釈を要する表現を避け、一般的な語彙や平易な表現を使う

## 書き換えの手順

- 書き換える前に、その節を最初から最後まで読む
- 書き換える前に、書き換える主張が後の節でどう使われているかを確認する
- 書き換えた後、指摘された一文だけでなく、ブロック内の全文を上の全規則で検査する
- 書き換えた後、節全体を読み直し、前後と重複する文を消す
